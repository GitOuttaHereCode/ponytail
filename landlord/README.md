# Small Landlord Books

Bookkeeping for 1-8 unit landlords. Open `index.html` in a browser. No install, no server.

- **Dashboard:** value, equity, rent roll, occupancy, NOI, cap rate, expense ratio, weekly tip, alerts.
- **Money:** income/expenses by Schedule E line (utilities split by type), trailing 12 months.
- **Tenants, Maintenance, Contractors:** contact info, leases, tickets, insurance expiry.
- **Market value:** add a free RentCast API key in Settings for address lookups, or enter from Zillow.

Data stays in your browser. Export a backup from Settings. Tests: `node --test landlord/`.
